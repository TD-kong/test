# 処方箋管理ツール(お薬手帳＋処方箋控え)

完全オフラインで動く処方箋・服用期間の管理アプリです。外部CDN・フォント・API通信は一切使いません。

## 使い方
1. `index.html` をブラウザで開きます(`file://` 直開きで動作します)。
2. 「新規登録」(スマホは右下の＋)から処方箋を登録します。
3. 初回はサンプルデータで試せます。ヘッダーの「?」で使い方を確認できます。

## ステータス判定(基準日=今日のローカル日付)
- 未調剤: 処方日を含め4日間(処方日+3日の末日)が受取期限。残り日数/超過日数を表示。
- 終了予定日 = 処方日 + (処方日数 - 1)日。
- 終了済み: 終了予定日 < 今日 / まもなく終了: 残り0〜3日 / 服用中: 残り4日以上。

## ファイル構成
- `index.html` 画面とSVGアイコン定義
- `css/style.css` ライト/ダークテーマ・レスポンシブ
- `js/utils.js` 日付計算・URL検証・ID生成・DOM補助
- `js/storage.js` localStorage、検証、容量算出、JSON入出力、タブ間同期
- `js/app.js` 状態管理・描画・フォーム・Undo・チュートリアル
- `assets/icon.svg` アプリアイコン

## バックアップ
- ヘッダー/設定の「書き出す」で `prescription-backup-YYYYMMDD-HHmm.json` を保存します。
- 「読み込む」で、既存データへのマージ(同一IDは更新日時が新しい方)か全置換を選べます。
- 最終バックアップから14日以上経過し未保存の変更があると、リマインダーを表示します。
- データはブラウザごとに保存されます。ブラウザのデータ削除で消えるため、定期的にバックアップしてください。
