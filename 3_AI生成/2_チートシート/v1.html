Web Development Cheatsheet

HTML / CSS / JavaScript の基礎知識をサクッと確認

HTML (HyperText Markup Language)

基本構造

HTMLドキュメントの基本テンプレート

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>Title</title>
</head>
<body>
</body>
</html>

見出しタグ

h1からh6まで、情報の重要度に応じて使用します。

<h1>最上位見出し</h1>
<h2>中見出し</h2>

リンク (Anchor)

別のページやファイルへのリンクを作成します。

<a href="https://example.com" target="_blank">リンク名</a>

画像表示

画像を表示します。alt属性は必須級です。

<img src="image.jpg" alt="説明文">

CSS (Cascading Style Sheets)

基本セレクタ

要素、クラス、IDを指定してスタイルを適用します。

/* 要素 */ p { color: red; }
/* クラス */ .class { ... }
/* ID */ #id { ... }

Flexboxレイアウト

柔軟な要素の整列・配置を行います。

.container {
  display: flex;
  justify-content: center; /* 左右中央 */
  align-items: center;     /* 上下中央 */
}

Gridレイアウト

行と列の二次元グリッドを定義します。

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 10px;
}

メディアクエリ

画面サイズに応じたデザイン（レスポンシブ）の切り替え。

@media (max-width: 768px) {
  body { font-size: 14px; }
}

JavaScript

変数宣言

データの保存には基本的に const や let を使います。

const name = "Taro"; // 再代入不可
let count = 0;       // 再代入可能

関数 (アロー関数)

処理をまとめるモダンな書き方。

const add = (a, b) => {
  return a + b;
};
// 省略形
const multiply = (a, b) => a * b;

DOM操作

HTMLの要素を取得・操作します。

const btn = document.querySelector('#myBtn');
btn.addEventListener('click', () => {
  alert('Clicked!');
});

条件分岐・ループ

条件による処理の分岐と繰り返し処理。

if (score >= 80) {
  console.log("Good!");
}
// 配列のループ
const arr = [1, 2, 3];
arr.forEach(num => console.log(num));
